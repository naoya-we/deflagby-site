MERITS

湘南交通で働く
5つのメリット

あなたが安心して、長く、充実して働けるための環境を整えています

01

二種免許の取得費用を全額補助

タクシードライバーに必要な「第二種運転免許」。取得には通常20〜30万円の費用がかかりますが、湘南交通ではその費用を全額会社が補助します。研修期間中も養成費として給与を支給するため、収入の心配なく技術習得に集中できます。

  • ✓ 二種免許取得費用 全額会社負担
  • ✓ 研修期間中も養成費を支給
  • ✓ 免許取得から現場デビューまでしっかりサポート
02

ベテランによる温かいサポート

高度なノウハウを持つベテランドライバーとオペレーターが、思いやりをもって一人ひとりに寄り添います。「わからないことは何でも聞ける」環境が、新人の皆さんの早期活躍を支えます。

  • ✓ マンツーマン同乗研修
  • ✓ 経験豊富なオペレーターが無線でサポート
  • ✓ 困ったことはいつでも相談できる体制
03

清潔な大浴場で疲れをリセット

勤務後は社内の大浴場でゆっくりと疲れを癒せます。清潔感にこだわった浴場で、体も心もリフレッシュ。健康的なコンディションを保ちながら働けます。

  • ✓ 社内に大浴場完備
  • ✓ 常に清潔に保たれた環境
  • ✓ 仕事後の疲労回復をサポート
04

仮眠室で体調万全に

夜間勤務前後にしっかり休める仮眠室を完備。ベッドが整備された清潔な空間で、十分な休息を取ってから勤務に臨めます。ドライバーの体調管理を会社全体でサポートします。

  • ✓ 仮眠室完備（ベッド・寝具あり）
  • ✓ 体調を整えてから出庫できる
  • ✓ ドライバーの健康を最優先
05

安定した収入と長期キャリア

湘南エリアで長年の実績を持つ安定した会社基盤。タクシードライバーとして腕を磨き、将来はオペレーターや管理職へのキャリアアップも可能です。長く安心して働ける環境を提供しています。

  • ✓ 安定した経営基盤
  • ✓ キャリアアップの道が開かれている
  • ✓ 賞与・各種手当充実
